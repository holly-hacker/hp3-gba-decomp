# Syntax:
# label <address> <name>
#   A symbol that can be addressed by other code, see also ram_symbols.us.inc.
#   Not intended for code, use `thumb-func` or `arm-func` instead.
#
# thumb-func <address> <name>
#   Same as `label`, but for a Thumb code entry point whose address is taken
#   directly (e.g. stored in a function-pointer table) rather than only
#   reached via `bl` -- marks the symbol `.thumb_func` so its value carries
#   the low bit real Thumb function pointers always have.
#
# asm-file <start> <end> <path.s> <name>
#   A region of committed assembly code.
#
# c-file <start> <end> <source.c> <name>
#   A region for a compiled C file.
#
# c-file-O1 <start> <end> <source.c> <name>
#   Same as `c-file`, but compiled with -O1 instead of -O2.
#
# c-rodata <start> <end> <name>
#   Places the .rodata of the `c-file`/`c-file-O1` row named <name> at its
#   own address, for an object whose read-only data the ROM keeps apart
#   from its code. Without such a row, a C file's .rodata is part of its
#   own region.
