# Extracted-region manifest for the US ROM.
#
# label <address> <name>
#   Declares a symbol at an address that isn't extracted yet (still raw
#   .incbin) but needs to be referenced from code that IS extracted.
#
# <start> <end> <asm-file> <name>
#   A curated, hand-verified extracted region. Boundaries must be fully
#   confirmed (all reachable code walked to genuine termination) before
#   a function earns a row here -- see docs/ for how each was confirmed.
#
# Everything not covered by a region stays as raw .incbin from
# baserom.us.gba, emitted as gap sections by tools/gen_link.py. Nothing
# it generates is committed, same as everything else in build/.
#
# A row whose asm-file is also listed in regions.jp.txt at the same
# address must be byte-identical in both ROMs at that address (verified,
# not assumed -- see the file itself for how).
#
# c-file <start> <end> <source.c> <name>
#   A region compiled from C by tools/c/compile_c.py (the `compile-c`
#   recipe) with agbcc, the compiler the ROM was built with -- see
#   docs/compiler.md. Column 3 is the .c under src/; the assembly it
#   produces lands in build/<ver>/c/<name>.s.
#
# krawall-module/krawall-samples <start> <end> <source> <name>
#   See the "Krawall audio data" section below for these two directives --
#   curated JSON+WAV source under data/audio/, packed to real assembly by
#   tools/krawall/pack_krawall.py before `gen-link` (the `pack-krawall` recipe).
