# Region manifest for the US ROM; regions.jp.txt follows the same syntax.
# Rows are linked in order, each right after the one above at its own
# alignment. Extraction keeps the addresses it reads assets from in the
# donor ROM in its own scripts.
#
# label <region> <name>
#   A symbol other code can address, see also ram_symbols.us.inc: where
#   that region is stored.
# asm-file <path.s> <name>
#   Committed assembly.
# c-file <source.c> <name>
#   A compiled C file; c-file-O1 compiles it with -O1 instead of -O2.
# c-rodata <name>
#   The .rodata of the c-file row <name>, where the ROM keeps it apart from
#   the code.
# graphics <feature> <group>
#   A group of graphics, described in graphics/<feature>.yaml.
# krawall-module <json-file> <name>
#   A Krawall module and its patterns, packed from data/audio/modules/.
# krawall-samples <dir> <name>
#   The Krawall sample set and its pointer list, packed from data/audio/samples/.
# dialog-text <json-file> <name>, dialog-text-table <name>
#   One language's dialog text, and the table of language pointers, packed
#   from data/text/.
