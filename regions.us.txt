# Extracted-region manifest for the US ROM.
#
# label <address> <name>
#   Declares a symbol at an address that isn't extracted yet (still raw
#   .incbin) but needs to be referenced from code that IS extracted.
#
# <start> <end> <asm-file> <name>
#   A curated, hand-verified extracted region. Boundaries must be fully
#   confirmed (all reachable code walked to genuine termination) before
#   a function earns a row here -- see docs/ for how each was confirmed.
#
# Everything not covered by a region stays as raw .incbin from
# baserom.us.gba, filled in by tools/gen_rom_s.py. The file it generates
# (build/us/rom.s) is never committed, same as everything else in build/.
#
# A row whose asm-file is also listed in regions.jp.txt at the same
# address must be byte-identical in both ROMs at that address (verified,
# not assumed -- see the file itself for how).
#
# krawall-module/krawall-samples <start> <end> <source> <name>
#   See the "Krawall audio data" section below for these two directives --
#   curated JSON+WAV source under data/audio/, packed to real assembly by
#   tools/krawall/pack_krawall.py before `stitch` (the `pack-krawall` recipe).

# --- Dialog/UI text data ---
#
# dialog-text <start> <end> <json-file> <name>
#   One language's full string table (Huffman tree + offset table +
#   2767 compressed strings, byte-aligned per string, 4-byte-aligned as
#   a whole -- see docs/formats/text.md and tools/text/text_codec.py), packed
#   from curated data/text/<lang>.json by tools/text/pack_text.py before
#   `stitch` runs (see the `pack-text` recipe). US/EU cart only --
#   dialog text has not been located in the JP ROM (very likely a
#   different mechanism, not proven identical the way Krawall content
#   is -- see docs/formats/text.md).
#
# dialog-text-table <start> <end> <name>
#   The 8-entry per-language pointer table (sub_08042588's
#   0x0806BD78) that all 8 dialog-text rows above are addressed from,
#   in the fixed language order English US, English UK, French, German,
#   Spanish, Italian, Dutch, Danish.
#
# data/text/ is curated, editable source (JSON), gitignored per hard
# rule 2 (CLAUDE.md) -- game's real dialog/UI text content, same
# footing as the baserom and data/audio/. Bootstrap it locally with
# `just migrate-text` before building. tools/text/pack_text.py writes the
# actual packed assembly to build/<ver>/text/ (also gitignored), which
# is what gen_rom_s.py includes.
