# Extracted-region manifest for the US ROM; regions.jp.txt follows the same
# syntax. Rows are sorted by address; unclaimed bytes are taken from the
# baserom.
#
# label <address> <name>
#   A symbol other code can address, see also ram_symbols.us.inc. Code
#   entry points use `thumb-func` or `arm-func` instead.
# thumb-func <address> <name>
#   A Thumb entry point whose address is taken directly (e.g. stored in a
#   function-pointer table): the symbol carries the Thumb bit.
# arm-func <address> <name>
#   A confirmed ARM entry point.
# asm-file <start> <end> <path.s> <name>
#   Committed assembly.
# c-file <start> <end> <source.c> <name>
#   A compiled C file; c-file-O1 compiles it with -O1 instead of -O2.
# c-rodata <start> <end> <name>
#   The .rodata of the c-file row <name>, where the ROM keeps it apart from
#   the code.
# graphics <start> <end> <feature> <group>
#   A group of graphics, described in graphics/<feature>.yaml.
# krawall-module <start> <end> <json-file> <name>
#   A Krawall module and its patterns, packed from data/audio/modules/.
# krawall-samples <start> <end> <dir> <name>
#   The Krawall sample set and its pointer list, packed from data/audio/samples/.
# dialog-text <start> <end> <json-file> <name>, dialog-text-table <start> <end> <name>
#   One language's dialog text, and the table of language pointers, packed
#   from data/text/.
