# Extracted-region manifest for the US ROM.
#
# label <address> <name>
#   Declares a symbol at an address that isn't extracted yet (still raw
#   .incbin) but needs to be referenced from code that IS extracted.
#
# <start> <end> <asm-file> <name>
#   A curated, hand-verified extracted region. Boundaries must be fully
#   confirmed (all reachable code walked to genuine termination) before
#   a function earns a row here -- see docs/ for how each was confirmed.
#
# Everything not covered by a region stays as raw .incbin from
# baserom.us.gba, filled in by tools/gen_rom_s.py. The file it generates
# (build/us/rom.s) is never committed, same as everything else in build/.
#
# A row whose asm-file is also listed in regions.jp.txt at the same
# address must be byte-identical in both ROMs at that address (verified,
# not assumed -- see the file itself for how).
#
# The Krawall audio rows below (samples/modules/patterns) are generated by
# tools/extract_krawall.py, not hand-written -- but ARE listed here like
# everything else, one row per region. Their asm-file always ends in
# `.bin`: gen_rom_s.py .incbin's these directly (no wrapper .s needed).
# The .bin files themselves are gitignored (asm/krawall/) and regenerated
# locally by tools/extract_krawall.py before building -- they're the
# game's actual copyrighted audio content, unlike this manifest, which is
# just addresses/names. See docs/formats/krawall.md.
#
# Known gap: a handful of module headers are followed by a real unclaimed
# gap (largest ~22KB) that isn't sample/pattern trailing padding -- every
# sample's and pattern's own trailing padding is fully accounted for by
# exact formulas in extract_krawall.py (asserted, not assumed: it refuses
# to generate if any sample/pattern doesn't land exactly on the next
# region's start). These particular gaps most likely hold additional
# modules that unkrawerter's own discovery never found -- see
# docs/formats/krawall.md's Open questions and Future work. Doesn't
# affect correctness either way (unclaimed bytes just stay as safe raw
# .incbin from the baserom, like any other gap).
