# krawall-module <start> <end> <json-file> <name>
#   A module (song) plus its own patterns, packed from curated
#   data/audio/modules/<name>.json (+ the sample WAVs it references) by
#   tools/krawall/pack_krawall.py before `gen-link` runs (see the `pack-krawall`
#   recipe). One row per module: a module's own patterns are contiguous
#   with each other and immediately precede its header in ROM, so the
#   whole [patterns][header] span is one region -- confirmed in
#   docs/formats/krawall.md.
#
# krawall-samples <start> <end> <dir> <name>
#   The entire sample set (all Sample<N> structs + PCM, then the sample
