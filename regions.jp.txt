# --- Krawall audio data ---
#
# krawall-module <start> <end> <json-file> <name>
#   A module (song) plus its own patterns, packed from curated
#   data/audio/modules/<name>.json (+ the sample WAVs it references) by
#   tools/krawall/pack_krawall.py before `gen-link` runs (see the `pack-krawall`
#   recipe). One row per module: a module's own patterns are contiguous
#   with each other and immediately precede its header in ROM, so the
#   whole [patterns][header] span is one region -- confirmed in
#   docs/formats/krawall.md.
#
# krawall-samples <start> <end> <dir> <name>
#   The entire sample set (all Sample<N> structs + PCM, then the sample
#   pointer list) as one region -- also one contiguous run, confirmed in
#   docs/formats/krawall.md. Packed from curated data/audio/samples/.
#
# data/audio/ is curated, editable source (JSON metadata + WAV PCM),
# content-identical between US/JP (see docs/formats/krawall.md's Confirmed
# stats) -- only the addresses below are per-version. It's gitignored, same
# footing as the baserom (see AGENTS.md hard rule 2) -- bootstrap it
# locally with `just extract-krawall` before building. tools/krawall/pack_krawall.py
# writes the actual packed assembly to build/<ver>/audio/ (also gitignored,
# like everything else in build/), which is what gen_link.py includes.
